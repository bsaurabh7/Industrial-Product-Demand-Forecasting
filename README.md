# Industrial Product Demand Forecasting

## Overview
A machine learning project to forecast industrial product demand using historical Kaggle transaction data.

## Techniques Used
- Data cleaning and preprocessing
- Feature engineering and outlier detection
- K-Means clustering for demand regimes
- Random Forest Regressor
- PyTorch MLP Regressor

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Asymmetric business penalty (2× penalty for under-prediction)

## Technologies
Python, Pandas, NumPy, Scikit-learn, PyTorch, Matplotlib.

## Dataset
Kaggle industrial product demand dataset.
